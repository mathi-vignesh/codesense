🛡️ RepoGuard: AI-Powered Security & Structure Analyzer
RepoGuard is a powerful command-line tool that provides a rapid, three-layer analysis of any Git repository. It's designed for developers who need a deep, AI-driven understanding of a codebase's structure, potential vulnerabilities, and overall health without manual inspection.
How It Works
RepoGuard performs a comprehensive analysis in three distinct layers:

Layer 1: 🗺️ Repository Summarization
What it does: Uses Repomix to scan your entire repository—including the file structure and the content of key files.
What it produces: A single, clean Markdown file (document1.md) that is perfectly formatted for review or for use with Large Language Models (LLMs).

Layer 2: 🐍 Static Security Analysis
What it does: Leverages Bandit, a best-in-class security linter, to perform a static analysis of your Python code.
What it produces: Actionable JSON reports detailing common security vulnerabilities. It even redacts potential secrets it finds and logs them securely for your review.

Layer 3: 🧠 AI-Powered Analysis
What it does: Combines the outputs from Layer 1 and 2 and sends them to the Google Gemini LLM for an expert-level review.
What it produces: A detailed, human-readable report (llm_analysis.md) containing insights on vulnerability hotspots, potential dynamic issues, and code workflow improvements.

**Getting Started**
Follow these steps to get RepoGuard up and running in minutes.
Prerequisites
Python 3.9+
Node.js (LTS): Required for the Repomix tool. You can download it from nodejs.org.
Git
1. Installation
First, clone the repository and navigate into the project directory.
git clone [https://github.com/your-username/repoguard.git](https://github.com/your-username/repoguard.git)
cd repoguard


Next, create and activate a virtual environment.
# Create the environment
python -m venv venv

# Activate on Windows (PowerShell)
.\venv\Scripts\Activate.ps1

# Activate on macOS/Linux
source venv/bin/activate


Finally, install the required dependencies and the RepoGuard tool itself.
# Install required Python packages
pip install -r requirements.txt

# Install the repoguard command-line tool in editable mode
pip install -e .


2. Configuration for AI Analysis
To use the Layer 3 AI analysis, you must provide a Gemini API Key.
Get a Key: Obtain a free API key from Google AI Studio.
Set the Environment Variable: In your terminal, set the key as an environment variable. This keeps your key secure and out of the code.
On Windows (PowerShell):
$env:GEMINI_API_KEY="YOUR_API_KEY_HERE"

On macOS/Linux:
export GEMINI_API_KEY="YOUR_API_KEY_HERE"

(Remember to replace YOUR_API_KEY_HERE with your actual key).
Usage
Running an analysis is simple. Point RepoGuard at any local Git repository.
Standard Analysis (Layers 1 & 2)
repoguard analyze /path/to/your/repository


Full Analysis with AI (Layers 1, 2, & 3)
To enable the Gemini analysis, add the --ai-analysis flag.
repoguard analyze /path/to/your/repository --ai-analysis


Example:
repoguard analyze C:\Users\Dev\Projects\my-flask-app --ai-analysis


What You Get: The Output Files
After a successful run, a new outputs/ directory will be created with the following reports:
📄 document1.md: The complete repository summary generated by Repomix.
📄 document2_full.json: The complete, raw JSON output from the Bandit security scan.
📄 document2.json: A simplified, pretty-printed summary of the most critical vulnerabilities.
📄 document2.min.json: A compact, minified version of the simplified report.
🧠 llm_analysis.md: The AI-generated security and code quality report from Gemini (only created when using the --ai-analysis flag).
🔒 secrets_redacted.log: A log file detailing any potential secrets that were found and redacted from the reports.
